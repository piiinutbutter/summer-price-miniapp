# 바가지 타파 (Summer Price Tag)

여름 휴가지의 **공식 공시 요금**을 미리 확인하고 예산을 계산하는 토스 미니앱입니다.

> 2026 앱인토스 7월 바이브코딩 챌린지 출품작

## 무엇을 하는 앱인가

2026년 6월 해수욕장 파라솔·평상 **표준가격제**가 시행되어 지자체가 요금을 공시하지만, 정작 이용자는 그 정보를 모릅니다. 이 정보 비대칭을 해소하는 것이 목적입니다.

- **가기 전** — 목적지 요금표 확인, 일행 수에 맞춰 예산 계산
- **현장에서** — 부르는 값이 공시가와 얼마나 다른지 즉시 대조
- **어디서나** — 같은 지역 착한가격업소의 밥값 정보

## 화면 구성

```
홈          검색 · 내 주변에서 찾기 · 필터 · 카드 목록
 ↓
상세        대표 사진 · 표준가격표 · 현장가 확인 · 착한가격업소
 ↓
예산 계산기  일행 수 · 항목 선택 · 총액/1인당 · 공유·카드 저장
```

## 데이터

| 데이터 | 규모 | 출처 |
|---|---|---|
| 여행지 | 38곳 (공시가 17곳) | 지자체 공시 직접 조사 |
| 대표 사진 | 29곳 | 한국관광공사 TourAPI (공공누리) |
| 착한가격업소 | 963곳 / 22개 시군구 | 행정안전부 (2026-06-30) |

### 데이터 원칙

**확인되지 않은 가격은 싣지 않습니다.**

1. 지자체·주최 측 **공식 공시**에서 확인한 것만 기록
2. 모든 가격에 **출처 URL + 기준일** 표기, 앱 화면에도 노출
3. 확인 실패 시 추측하지 않고 `verified: false` + 가격 없음 (대신 문의처 안내)
4. 블로그·SNS 스크래핑 금지
5. **커버리지보다 정확성 우선** — 38곳 중 17곳만 가격이 있는 편이, 38곳 전부에 추측 가격이 있는 것보다 낫다

착한가격업소 데이터에는 좌표가 없어 거리 대신 **같은 시군구** 기준으로 묶었고, 화면에도 그렇게 명시했습니다.

### 바가지 판별에 대해

**앱이 "바가지"라고 판정하지 않습니다.** 공시가와 얼마나 다른지 사실만 전하고 판단은 사용자에게 맡깁니다. 업소명은 받지 않습니다.

```
파라솔 공시가 10,000원 + 현장 25,000원
  → "공시가보다 15,000원 비싸요 (150% 높음)"
  → 관광불편신고 1330 안내
```

## 실행

```bash
npm install
npm run dev      # 로컬 개발
npm run build    # .ait 번들 생성
```

### 검증

```bash
npx tsx src/budget.test.mjs     # 예산 계산 로직
npx tsx src/location.test.mjs   # 거리 계산·근처 정렬
npx tsc --noEmit -p tsconfig.app.json
```

## 데이터 갱신

```bash
# 여행지 사진 (TourAPI 키 필요 — .env.local에 TOUR_API_KEY 설정)
node fetch-images.mjs

# 착한가격업소 (공공데이터포털에서 CSV를 먼저 내려받아야 함)
node attach-shops.mjs
```

두 스크립트 모두 **개발 시점에 1회 실행**해 결과를 JSON으로 저장합니다.
앱 실행 중에는 외부 API를 호출하지 않습니다 — CORS 차단, 일일 호출 제한, API 키 노출을 모두 피하기 위함입니다.

## 기술 메모

- **의존성 최소화** — 공유 카드 이미지는 `html2canvas` 없이 표준 Canvas로 직접 그립니다
- **공유** — SDK 2.10.8에 Share API가 없어 `navigator.share` 우선, 실패 시 클립보드 폴백
- **권한** — `clipboard`(write), `geolocation`(access). 위치는 버튼을 누른 순간 1회만 조회하고 저장하지 않습니다

## 라이선스·저작권

- 여행지 사진: 한국관광공사 (공공누리 제1·3유형 — 출처 표시, 변형 금지)
- 착한가격업소: 행정안전부 공공데이터
- 요금 정보: 각 지자체 공시자료 (앱 내 출처 링크 제공)
